# TalkDesk 操作手册

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 商业咨询微信 zhuatech / zhuatech2。

## 管理员首次使用

从本机私有 `.env` 读取初始化账号及密码，不在聊天中发送密码。默认只有管理员。登录账号页新增组织、成员账号和角色，成员密码须12–72字节，包含大小写字母和数字。账号停用、密码重置和组织停用撤销旧登录资格，并由媒体巡检移出不再有权限的参与者。保留最后一位有效完整管理员。

“成员”可创建及加入房间，“组织管理员”可管理授权组织内的房间和成员，“统计查阅”只读取统计，不读取聊天正文。房主关系与菜单权限不是同一回事；管理房间还需 rooms 权限及正确组织范围。私有房间的内容不因持有统计权限而开放。

## 创建和加入房间

创建房间时填写名称、分类、说明、人数上限、私有/组织范围。人数上限同时约束成员关系和语音房配置。组织房由符合组织及角色范围的登录成员自行加入；私有房须由管理员创建登录账号后，房主发放有限期、限次数的邀请代码。邀请不能替代登录或组织权限，也不能解除禁入。

邀请原文只在创建时显示，请通过适当的私有渠道交给成员。列表只展示使用量与有效期。撤销、过期和用完均不可兑换。成员禁入后不能重新加入；解除禁入不会自动恢复成员关系，需要重新加入或兑换新邀请。

## 聊天与语音

文字消息由服务器存储。显示最近50条，可加载更早消息。消息发送有去重键；网络中断显示结果未知时先刷新核对，不要反复提交。本人或有房间管理权的人员可移除正文，保留时间、作者及移除标记；被移除的正文不再通过接口返回。

点击“加入语音”默认静音，不自动采集麦克风。只有明确点击“开启麦克风”才请求设备权限。音频设备页可选择输入设备与自动/中继连接方式，应用后重新连接。切换连接会默认恢复静音。出现自动播放提示时点击开启声音。浏览器没有设备或拒绝权限时仍可收听；请在站点权限中核对，不需要关闭浏览器安全保护。

网络短暂中断由 SDK 尝试重连，界面显示重连状态；权限撤销、锁房、归档及媒体服务重建后可能需要重新加入。Docker 本机回环地址可测试直接链路；强制 TURN 应使用客户端可达的实际服务器地址，参见部署手册。设备页的音频包计数来自实际 WebRTC 接收统计，不代表人工听感或线路质量保证。

## 状态、成员与记录

锁定房间保留已有成员的聊天查阅，禁止新发送和语音；重新开放生成新的语音代际。归档后不可重新开放或编辑。房主离开前应转让给有效成员；只有有效成员可接任。禁入和停用先阻断网关重连，现有连接由两秒巡检移出，服务异常时保留撤销记录待重试。

统计和CSV按组织范围过滤，只导出房间名称、状态、成员关系数和消息条数，不导出聊天正文、邀请或语音票据。操作记录不保存聊天正文和密码。菜单可改名、排序及启停；权限代码和系统参数代码是固定目录，不支持在页面中虚构新的接口权限。
